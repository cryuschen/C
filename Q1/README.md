## 关键评价指标

1. **去噪有效性：**半合成注入后的归一化恢复 RMSE 是有可计算目标的主要指标，须与未经额外校正的预处理输入配对比较。0 倍注入的恢复 RMSE 衡量对背景的误改。外折训练模板 MAE 降幅只作为真实数据的代理证据：四组 V7 点估计为 10.0%、8.2%、5.4%、9.8%，对应的组内试次重采样区间均高于零。
2. **条件差保留：**半合成的左右差分恢复 RMSE 优先于仅比较处理前后差分幅度。真实数据的左右差分幅度保留比为 0.934、0.952、0.942、0.813；前后半段三通道合并波形相关为 −0.322、+0.767、+0.476、−0.400。后者说明四组中有两组方向差异未显示时间稳定性。
3. **辅助诊断：**SNR 代理增量的四组 95% 组内试次重采样区间均跨零，不能写成稳定提升。单试次分解图、热力图和样条拟合图用于展示处理过程或波形形态，不充当“去噪且保留视觉特征”的主要证据。

这些是四组开发数据的结果，不是独立受试者泛化检验。V7 在校正时已知视觉提示方向，且仅有 Fz、F3、F4 三个额区通道；因此图表可支持“观测到的左右提示相关差异在处理后部分保留”，不能证明形状特异神经信号被无损恢复，也不能证明未知提示解码或脑源定位。

`metrics/` 中只保留绘制与复核这三张图需要的 V7 和预处理指标。波形曲线由 `eeg_v7_results/` 四组 `可复核波形.npz` 中的预处理及 V7 数组重算。
