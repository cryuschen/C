# 第二问 V3 验收口径

本文件在查看 V3 新模型结果前记录判定方法，防止把开发集上的最好数字误写成第二问已完成。原题要求：（1）建立 LGN→皮层→头皮 EEG 计算模型；（2）用模型解释左右三角刺激造成的 EEG 差异；（3）给出区分两类视觉刺激响应的特征表示。

## 固定数据与流程

- 使用题目四份 MAT 的原始 Fz、F3、F4（前 3 通道），VisCue 左 −1、右 +1；通道 4–6 不能用作干净真值。
- 主评价沿用五个独立连续时间块、同一套固定质量规则；外层测试方向只在最终评分时读取。任何含标签的去噪、空间滤波、模板、特征筛选、标准化、超参数和分类器都只能在外层训练折拟合。
- 刺激前负对照只能读取提示开始之前的数据；若使用零相位滤波，应从严格在提示前结束的片段单独计算。其分类器、划分和置换口径应与刺激后主模型一致。
- 四份 MAT 已经反复用于开发。新的 p 值可以作内部探索证据，不能当作独立复制。报告所有尝试的候选，不只报告最优者。

## 机制模型应交付的证据

1. 画出并计算左右输入的空间组合选择性、群体动力学和三通道投影；模型参数、假定几何及其来源可复现。
2. 用训练块估计必要参数，在留出块预测**右减左**条件 EEG 差分。报告每组和合并加权误差，以及相对“无方向差”的 `S_Δ=1−MSE_model/MSE_zero`。若只在仿真里产生差异、却不能改善真实差分留出误差，不能称为解释了实测差异。
3. 对照共同响应、无方向差和至少一种眼动／任务准备替代解释；报告参数稳定性与失败组。即使拟合成功，三个额区电极且无 EOG／眼位仍不能唯一定位真实脑源，结论只能是数据支持的候选机制。

## 判别特征应交付的证据

1. 给出未知试次仅凭 EEG 可计算的特征公式和逐试次导出文件。对照固定的基础方法，报告每组及合并的时间留块 BA、AUC、类别召回率。
2. 在块内置换方向标签，**重新运行全部监督步骤**，对本轮多个候选算法作相应多重比较校正。不能移用旧模型的 p 值。
3. 检验刺激前特征是否也能识别标签，并检验刺激后表示相对刺激前信息的增量。若刺激后效果与刺激前相近，或控制刺激前后消失，不能把它命名为三角视觉响应特异表示。
4. 图表须标明横轴、时间窗、受试者／项目、试次数和不确定性；最终图像应实际打开检查。

## 完成判定

可运行模型、候选特征和仿真图只完成**构建**。在现有四份 MAT 上，只有机制差分的留出预测与刺激后增量判别均得到一致支持，才能写作“模型解释了观测差异，并提出了经内部验证的区分表示”。即便如此，也要注明开发数据、多次探索、缺少眼位与源定位的限制；不得宣称唯一证明真实神经因果路径或跨人群推广。
