本目录保留原始建模方案，并新增可运行的计算实现。运行方法见 [计算实现说明](README_运行.md)，入口为 `run_q2.py`；实际完成状态与实验性能以项目根目录 `Q2_result/manifest.json` 和 `Q2_result/第二问实验报告.md` 为准。原讨论文档记录的是实现前状态。

方案承接 `eeg_v7_results/` 的 V7 可复核波形以及 `Q1/` 的最终图表，提出空间排列选择性、神经群体动态与头皮前向观测模型，并给出三空间模态的可估计约化形式、九维特征表示和完整验证路线。

`source_figures/` 为阅读题目时从原始 DOCX 提取的插图，包含原题图像及阅读用缩略图，不属于第二题计算结果。
