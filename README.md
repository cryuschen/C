# 数模三题最终版

所有正式材料集中在 **[最终版/README.md](最终版/README.md)**。建议从该文件阅读三题报告、图表与结论边界。

- [最终版完整工程](最终版/完整工程)：源代码、题目、四份 VisualCog 原始数据、结果和复现依赖。
- [文件整理与验收](最终版/验收与清单)：路径对照、哈希清单和整理后测试记录。
- `三题最终版.zip`：最终版的便携副本，包含数据与复现代码，不包含本机虚拟环境或临时缓存。
- `整理归档/`：本机缓存和办公临时文件，正式交付不需要。

在本目录运行验收：

```bash
python3 最终版/main.py --stage verify
```

完整重新计算：

```bash
python3 最终版/main.py --stage all
```

入口会优先使用已激活的虚拟环境，否则寻找本项目现有 `.venv`。`.venv`、`.git`、`.vscode` 等本机环境和开发配置保留在根目录。两套外部参考数据集 `v1.0.1`、`v1.0.2` 已按要求删除，未放入归档或交付包。
