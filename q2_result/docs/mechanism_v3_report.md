# 第二问机制模型 V3：图像驱动的方向差分留块检验

## 要检验的主张

原题要求从 LGN、皮层群体活动到头皮 EEG 建模，并**用所建模型解释实测左右三角 EEG 差异**。V3 把题图内嵌的右向三角示意图与其镜像送入局部方向边缘选择器；两个方向选择群的不同输入驱动固定兴奋／抑制神经群体，经突触电流形成时间响应。LGN 低通、兴奋／抑制方程及示意导联几何沿用 `q2model/mechanism.py`，本次运行在读入 EEG 前固定；它们并非独立数据上的预注册参数。题图是示意图，**不是校准过的显示器刺激记录**。

与 V2 单个固定时间模板不同，V3 把神经群体右减左突触响应 `q_R(t)−q_L(t)` 延迟 0、90、180 ms，得到三个假定的传播阶段。随后使用与 EEG 相同的零相位滤波处理模板。对每个通道 `c`，仅从外层训练试次估计三个有效头皮增益 `a_{ck}`：

`Δx̂_c(t)=Σ_k a_{ck} h_k(t)`；`a=argmin_a ||Δx_train−aHᵀ||²_W + λ||a||²`。

这里 `Δx` 为右向条件 ERP 减左向条件 ERP，`W` 在提示后 50–250、250–500、500–750 ms 三窗口等权。`λ∈{0.1,0.3,1,3,10,30,100}` 仅由外层四个训练块的内层留一块选择。三路额区增益是**有效参数**，不是定位出的视觉脑源。

两种同样使用三个时间基、每通道三个自由增益的替代解释也在相同划分和内层流程下测试：80、180、320 ms 平滑阶跃（眼动候选），以及 0、180、350 ms 起始的慢斜坡（准备／慢漂移候选）。共同 ERP 预测左右相同，其方向差分正好等于零差分基线。

## 原始数据和时间分割

只用四份 MAT 中的原始 Fz、F3、F4 与 VisCue 方向码；每份 100 次提示。0.1–30 Hz 和 60 Hz 陷波、24 秒分块边缘缓冲、固定无标签质量规则沿用 `q2model/data.py`；保留 A1/A2/B1/B2 分别 67/70/69/69 次。每份按原始试次时间分为五个连续块；每次留一个块测试，超参数只在其余四块中选择。每组输出五折，全部四组合计二十折。`inner_choices.json` 列出每折训练／测试试次编号、全部内层误差及所选岭系数；`*_heldout_waveforms.npz` 保存各折观察和预测的三通道右减左波形。

`S_Δ = 1 − mean_f MSE_f / mean_f MSE_zero,f`，其中 `MSE_f` 是该组各外层测试块上右减左差分的三通道等窗加权误差；`S_Δ>0` 才表明优于无方向差预测。合并行对四组的二十个外层块等权，**不是独立研究样本数**。

| 模型 | A1 | A2 | B1 | B2 | 合并等折 |
|---|---:|---:|---:|---:|---:|
| 图像驱动神经群体 | −0.0324 | −0.0666 | −0.0060 | +0.0940 | +0.0061 |
| 平滑眼动阶跃替代 | −0.1637 | −0.2710 | −0.0261 | **+0.2344** | −0.0281 |
| 慢斜坡替代 | −0.1556 | −0.2828 | −0.0427 | +0.1793 | −0.0494 |
| 共同 ERP／无方向差 | 0 | 0 | 0 | 0 | 0 |

前三组的神经群体模板均不及零差分；B2 虽有正收益，但平滑眼动和慢斜坡模板在同一外层检验中更好。神经模板二十折只有 12 折 `MSE_model<MSE_zero`，岭系数在不同折覆盖完整 0.1–100 网格，说明方向参数不稳定。刺激前单独截止的 250 ms 片段也以三项低阶多项式做同样时间留块的差分转移负对照，A1/A2/B1/B2 `S_Δ` 分别为 −0.1721/−0.2655/−0.0024/−0.0175；这个负结果**不能排除**非线性准备或刺激后眼动。

图见 [V3 留出比较](../results/mechanism/heldout_comparison.png)，标明刺激后时间窗、每组试次数及五块重抽样描述性范围；数值见 [四组汇总](../results/mechanism/heldout_summary.csv)、[合并汇总](../results/mechanism/pooled_summary.csv)、[逐折误差](../results/mechanism/heldout_folds.csv)、[五块重抽样范围](../results/mechanism/fold_resampling_ranges.csv)与[刺激前对照](../results/mechanism/prestim_summary.csv)。重抽样只有每组五块，区间用于展示折间不稳定，不能当独立实验的置信区间。图已打开目检。

看过上述主结果后，又做了**探索性增量试验**：把三项神经基叠加到三项眼动阶跃基或慢斜坡基，仍按相同外层时间块和训练块内岭选择比较。相对于单独眼动基，叠加神经基对 A1/A2/B1/B2 的 `S_Δ` 增量分别为 +0.0007/−0.0088/−0.0044/−0.0701；相对于慢斜坡基则为 −0.0221/−0.0027/+0.0215/+0.0013。没有跨四组稳定的神经基独有预测收益。见 [增量汇总](../results/mechanism_incremental/incremental_summary.csv)与[增量程序](../../q2/mechanism_v3_incremental.py)。这是查看主结果后的二次分析，不能当独立确认。

## 判定与边界

V3 提供了题意所需的**可运行生成路径**和训练块到留出块的直接检验，却未在四组实测数据上稳定改善方向差分；因此不能声称已经解释真实 EEG 差异的形成机制。B2 的平滑眼动候选更接近观察差分，也不证明信号一定是眼动。只有三路额区 EEG、无同步 EOG／眼位且未知个体导联，神经与眼动来源仍不可辨识。四份 MAT 已被用于多轮方法开发，本轮结果亦属开发集内部评估。
