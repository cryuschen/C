# 第三问 V3：应答不确定性与统一认知决策模型

V3 补全两处内容：缺少明确应答时的 EEG 观察窗与删失规则；直接由 V2 认知状态驱动的正确、错误、未越界决策仿真。原始 `q3`、`q3_result`、`q3_result_v2` 不修改。

代码位于 `q3_v3`，新结果位于 `q3_result_v3`。原始四份 MAT 继续从 `data` 只读加载，SHA256 记录在新清单。视觉模型通过大小写正确的 `Q2.q2model.generative` 导入；不依赖 V1 决策模块，不需要 Linux 的 fcntl。

## 本轮固定方案

以下方案在本轮结果生成前写入，不是外部预注册；既有数据已经用于多轮开发。

- 神经状态、头皮读出、V2 的参数搜索与原有结果保持原定义。主分析重建 V2 外层预测并复核；不将“冻结参数重建”称为重新拟合。复制的 V2 证据集中放在 `inherited_v2`，新结果标明来源。
- 已观测应答和 Task-1 平台末端代理：EEG 截止于应答/代理前 100 ms。正误不参与筛选。代理不冒充真实点击。
- 无明确应答：只要提示和候选目标可确定，允许保留 EEG，观察上限固定为候选目标后 2 s，同时受下一试次、记录长度和既有 24 s 块保护限制。1.5/2/2.5 s 只作冻结模型、共有试次上的窗口敏感性。没有点击标记既可能是未答，也可能是标记缺失，不能直接标作真实超时，不能自动作为有效行为生存删失样本。
- 已知点击晚于观察上限时，行为的时间截断可明确记为行政右删失；这仍不是实验超时。Task-1 代理单列。截止时间及正确目标映射缺失时，真实 correctness/timeout 保持未知。
- 当前实测没有可确认的无应答案例，因此另存“删除点击标记”“给定错误标签”等软件压力测试。它们仅验证实现，不进入实测统计，也不伪造错误样本。
- 决策层使用与 EEG 相同的 V2 `states`。取提示方向对齐的认知差分作为证据，给定仿真专用的正确目标侧映射，驱动带上下边界的随机累积。没有使用实测点击方向反推正确答案。
- 固定参考状态 τm=2 s、τp=0.3 s、目标脉冲 0.2 s；证据归一化固定由该状态给出。γ=1.5、σ=0.6、边界±1、仿真截止2 s，均为工程假设，未拟合真实正确率、反应时或超时率。弱保持、关闭提取、高噪声、低证据、短截止只改指定项。另用20组 V2 外层 EEG 所选参数驱动决策，仍不称为行为拟合。
- 首次触界为决策事件，未触界为右删失；没有决策时间的试次不填0或截止时间作为真实反应时。观察时长与决策时间分列，不加未经估计的运动时延。主表报告删失中位数和受限均值E[min(T,D)]；超过一半未决时不报告一个伪造的总体中位数。

## 运行

从项目根目录执行（Python 3.11+，依赖见 requirements.txt）：

```powershell
.venv/Scripts/python.exe -B -X utf8 -m unittest discover -s q3_v3/tests -v
.venv/Scripts/python.exe -B -X utf8 q3_v3/run.py
.venv/Scripts/python.exe -B -X utf8 q3_v3/audit.py
```

默认命令依次执行来源快照、事件与 EEG 重建、观察窗敏感性、统一决策仿真、报告绘图和独立复核。可用 `--stage render` 从已保存数值重绘。全部产物写入新目录，不覆盖旧结果。

这是一轮结构完整性补充，不以提高原有 EEG 或反应时分数为目标。背景辅助与前缀反应时的旧证据可在 inherited_v2 中复核；V3 没有重新执行1999次置换，也没有把旧检验标成新检验。
