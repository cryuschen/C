# 第二问当前结果：图像驱动的脑电形成模型

当前最终版本以 [q2/main.py](../q2/main.py) 为代码入口，采用图像驱动的三级兴奋—抑制（E/I）群体模型和独立时间块验证。结果直接保存在本目录根目录，文件采用 `Q2_` 前缀。

## 阅读入口

1. [论文正文](Q2_论文正文.md)：模型方程、验证设计、结果和结论边界。
2. [结论证据对照](Q2_结论证据对照.csv)：各项命题对应的证据与可写结论。
3. [结果索引](Q2_结果索引.md)：数值、图表及审计文件的完整索引。
4. [图注与使用说明](Q2_图注与使用说明.md)：正文图和补图的用途及解释。
5. [代码说明](../q2/README.md)：依赖、运行方式与实现约定。

## 当前方法与数据口径

- 主分析使用四份原始记录的 Fz/F3/F4 通道，采样率为 256 Hz；幅值沿用原始记录单位，未假定为微伏。
- 每份记录划分五个连续时间块，块内独立预处理，设置 24 s 边界保护；分析窗为提示前 250 ms 至提示后约 800 ms。
- A1、A2、B1、B2 分别保留 67、70、69、69 次，共 275 次试验。
- 形状编码驱动 LGN 中继与三级 E/I 群体动力学，经突触等效源及条件共享的观测矩阵形成头皮预测。参数在外层训练块内选型，测试块用于留出评价。
- Q1 的 before/v7 波形仅用于描述性衔接；方向知情的 V7 校正模板不进入当前主判别流程。
- 当前机制增强特征为 23 维；24 维协方差特征作为单独基线，不能混称为机制特征。
- 默认进行 1999 次块内置换、199 次循环移位和 1000 次块重采样。maxT 校正覆盖本次七组特征，不覆盖历史全部模型探索。

## 核心结果及解释

23 维机制特征的合并留出结果见 [特征判别表](Q2_表4_特征判别.csv)：

| 指标 | 当前结果 |
| --- | --- |
| 平衡准确率 BA | 44.7% |
| BA 的时间块重采样 95% 区间 | 40.2%–48.4% |
| AUC | 0.468 |
| 七特征组合 maxT 校正 p 值 | 0.9995 |

方向差分预测的留出改善率 SΔ 在 A1、B2 两组点估计为正，分别约为 0.0581、0.2562，但两组区间均跨零；A2、B1 点估计为负。完整数值见 [机制汇总](Q2_机制汇总.csv)。不能将“2/4 组点估计为正”写成“两组显著验证成功”。

当前结果支持建立并检验一个可计算、可消融的候选视觉形成模型，尚不支持稳定的未知方向识别或真实神经源的唯一恢复。模型内部状态不是实测神经活动，有效观测矩阵不是个体解剖导联；SΔ 与标准 R² 的基准也不同。两名受试者的数据和既有记录的块重采样不能作为人群泛化证据。

## 复现与复核

在项目根目录运行：

```bash
# 完整分析：会更新本目录同名 Q2_ 结果
.venv/bin/python -B q2/main.py

# 从已保存数值重绘、生成论文文字并核验
.venv/bin/python -B q2/main.py --redraw

# 运行测试
.venv/bin/python -B -m unittest discover -s q2/tests -v
```

其他环境使用 Python 3.11+，依赖见 [requirements.txt](../q2/requirements.txt)。`--no-plots` 可只计算；`--quick` 为快速检查，会覆盖同名结果，其低置换次数输出不能替代正式分析。自定义 `--output` 目录必须已存在。

来源与版本见 [运行清单](Q2_运行清单.json)，逐试次数值核验见 [结果复核](Q2_结果复核.json)，测试记录见 [测试验收](Q2_测试验收.txt)。

## 历史材料与后续模型

此前“第二问_Q1数据级联机制与判别模型.md”、`q1_model/`、`docs/`、`results/` 中的旧模型及报告仅保留作历史复核，不是当前主入口的结果。旧版 371 次试验、六时间核模型及 BA 54.5% 等数字不能与当前 275 次试验、三级 E/I 模型的结果混用。

第三问当前 [V3 说明](../q3/README.md)继承本版的形状编码和局部视觉动力学，并降维扩展为记忆、认知及决策状态；它重新处理长时间窗并估计宏观读出，不是直接串接 Q1 校正波形，也不是完整迁移 Q2 的最优参数与观测矩阵。

## 本轮优化

新增固定六维/三维投影，七组主特征共同重算1999次块内置换和199次循环移位。原机制特征分数未变，校正p值随比较范围变化。详见[优化报告](Q2_优化报告.md)。方向收缩未替换原主模型。
