# V3 候选机制：图像输入、群体动力学和头皮观测

原题 DOCX 内嵌的右向三角是实验示意图。V3 从中分离三角与注视圆，镜像得到左向输入；没有真实显示器的逐次像素、视角或位置记录。因此下列路径是**可运行的机制假说**，不是从这四份 EEG 识别出的生理事实。

## 从图像到方向选择输入

程序对图像做高斯差分和方向梯度，近似视网膜／LGN 的局部对比；分别沿左右三角的预设边缘位置取方向响应。每个方向选择群对多个边缘响应取带位置容差的几何平均：

\[
f_j(I)=\exp\left\{\frac1K\sum_{k=1}^{K}\log\left[\max_{\delta\in\mathcal N}
r_{\theta_{jk}}(p_{jk}+\delta;I)+\varepsilon\right]\right\},\quad j\in\{L,R\}.
\]

用题图编码得到左向 `(f_L,f_R)=(1,0.418)`，右向 `(0.418,1)`；共同注视圆作为第三输入。数值是模型输出，不是测得的神经元活动。实现见[图像编码](../../q2/q2model/stimulus_shape.py)。

## 从群体输入到观测

三个输入群 `j∈{L,R,C}` 各有传入驱动 `g_j`、兴奋状态 `E_j`、抑制状态 `I_j`：

\[
\tau_g\dot g_j=-g_j+u_j(t),\quad
\tau_E\dot E_j=-E_j+\sigma(E_j-I_j+\alpha(WE)_j+g_j-b),\quad
\tau_I\dot I_j=-I_j+\sigma(E_j-I_j-b).
\]

兴奋与抑制响应经不同突触核形成假定等效偶极，再由示意导联矩阵投影到 Fz、F3、F4：

\[
q_j=h_E*(E_j-E_{j,0})-0.7h_I*(I_j-I_{j,0}),\qquad
\widehat x_c=\sum_j L_{cj}q_j.
\]

模拟取 `τ_g=20 ms`、`τ_E=20 ms`、`τ_I=40 ms`，兴奋和抑制突触时间尺度分别为 25、75 ms。群体位置、导联矩阵与这些参数都是**假定值**；模型实现见[神经群体模拟](../../q2/q2model/mechanism.py)。实测检验另用外层训练块估计三通道有效增益，不把模拟导联矩阵当作已知个体头模型。细节和实际留出结果见[机制报告](mechanism_v3_report.md)。
