三题逻辑一致性审查（2026-09-26）

结论：以 `Q2/main.py` 当前入口及 `q2_result/Q2_论文正文.md` 为第二题版本基准，第三题 V1、V2 与第一题的基本逻辑能够衔接，没有发现必须推翻第三题模型的前后矛盾。但目前交付材料存在明确的第二题版本指引冲突；第三题继承模型、预处理、事件语义和验证结论的边界也需要在合并论文中统一。不能直接概括为“完全没有矛盾”。

本次阅读了题目 DOCX、Q1 V7 终稿、当前 Q2 论文与主要实现、Q2 旧版报告、Q3 两版报告，以及数据、视觉动力学、拟合、行为、仿真和测试代码。进行了原始数据重建、两版样本与掩码核对、行为指标重算及测试；没有重新运行完整候选搜索和 1999 次置换，也没有修改原模型或原结果。

**1. 最先需要解决的是第二题版本冲突。**

`q2_result/README.md:3` 仍指向“第二问_Q1数据级联机制与判别模型.md”，将其称作当前结果。该旧报告使用六个固定时间核、371 个 Q1 试次、24 维空间协方差特征，报告合并 BA 54.5%、AUC 0.571、199 次置换 p=0.050。

但 `Q2/README.md`、`Q2/main.py` 和 `q2_result/Q2_论文正文.md` 对应的是三级 E/I 群体模型、独立时间块预处理、275 个试次和 23 维机制增强特征；后者 BA 44.7%、AUC 0.468、五特征组合 maxT 校正 p=0.9985。当前新版也保留 24 维协方差基线，其 BA 是约 46.9%，不能用旧版的 54.5% 替代。

Q3 实际继承的是 `Q2/q2model/generative.py` 中的新版动力学。两个第二题版本使用不同数据流程与模型，得到不同数字本身不矛盾；同时把两者称为“当前第二题”却会造成论文证据链冲突。建议统一以当前代码及 `Q2_论文正文.md` 为准，将旧 README 和旧报告明确标注为历史版本。若拟提交论文仍采用旧版第二题，则必须先解释第二题模型升级，再接第三题，不能直接声称第三题沿用旧六核模型。

**2. 第一题与第三题的关系是共享原始数据与处理原则，不是直接串接 V7 输出。**

| 项目 | 第一题 V7 | 当前第二题主分析 | 第三题 V1、V2 主分析 |
|---|---|---|---|
| 原始通道与单位 | Fz/F3/F4，原始记录单位 | 相同 | 相同 |
| 设备 Decon 通道 | 不进入算法；图中可作展示 | 不进入主分析 | 不进入主分析 |
| 滤波 | 整段连续记录零相位 | 五个独立时间块零相位 | 五个独立时间块单向因果 |

| V7 方向知情校正 | 使用 | 仅作描述性衔接，不进主判别 | 不使用 |
| 外层划分 | 五折方向分层随机划分 | 五个连续时间块 | 五个连续时间块 |

Q1 需要已知方向选择校正模板，其终稿也明确不能证明恢复了纯神经信号。因此，Q2/Q3 从原始通道重新处理，避免把方向条件模板造成的结构当作模型发现，是合理的。Q3 改用因果滤波，也与限制应答后信息进入前缀分析的目的相符。

需要补足的衔接句是：“第一问的 V7 用于已知提示条件下的离线响应描述；后续机制检验从相同原始三通道重建独立时间块数据，并根据长认知窗与前缀信息限制采用因果观测滤波。”

不能写“第三问直接在第一问已去除眼动的干净信号上建模”。目前的 Q1 报告和 Q3 报告都没有证明信号已经无伪影。Q3 背景辅助模型预测到的慢变化也不能被命名为已分离眼动或已恢复海马信号。

**3. 样本数变化有合理来源，但第三题并不是第二题样本的简单子集。**

| 数据组 | Q1 | 当前 Q2 | Q3 V1 | Q3 V2 |
|---|---:|---:|---:|---:|
| A1 | 90 | 67 | 65 | 65 |
| A2 | 95 | 70 | 68 | 68 |
| B1 | 94 | 69 | 64 | 64 |
| B2 | 92 | 69 | 71 | 71 |
| 合计 | 371 | 275 | 268 | 268 |

实际对账发现，Q3 相对 Q2 新纳入 A2 第 45 次、B2 第 50 和 57 次。这不是两版 Q3 为了改善成绩修改样本，而是 Q2 与 Q3 的观测滤波、质量检查时段和饱和规则不同：Q1/Q2 短窗按绝对点数判定，Q3 长窗按比例判定；Q3 的质量统计使用提示后的分析段，Q1/Q2 质量检查还包含刺激前段。延长窗口也会改变峰峰值和饱和占比。因此“窗口更长，所以只会再剔除几个试次”的解释不准确。

Q3 V1 与 V2 保存的试次编号、块号、候选目标时刻、截止时刻和 EEG 数值完全相同；从当前原始 MAT 重建的最大绝对差约为 1.9×10⁻⁹，属于本次复算观察到的微小数值差异。两版 Q3 的配对比较具备同队列基础。行为分析的 139 次前缀队列另行筛查，不能把 139 与 268 相加当独立样本量。

**4. 第三题确实借用了第二题的形成机制，但继承的是结构，不是已标定的完整模型。**

当前 Q2 是 LGN、三级 E/I 群体、双级突触滤波，再将三个层级的九个等效源投影到头皮。Q2 的时间尺度和同级耦合强度通过训练内选型，观测矩阵也由训练数据估计。

Q3 V1 保留该局部动力学，但固定时间尺度倍率为 1、耦合为 0.1，只取最后视觉层三个群体，再加入慢记忆与认知状态。Q3 V2 直接调用 Q2 的 `simulate`，又将提示输出压缩为共同和方向差分成分，独立生成共同目标驱动。Q2 的观测矩阵没有直接迁移到 Q3，Q3 重新估计自己的读出。

这些是可以成立的降维与扩展假设，报告已经说明了其中多数内容。建议统一表述为：“继承第二问的形状编码及局部视觉动力学，固定局部参数并作输出降维，重新估计宏观状态的头皮读出。”避免使用“完整保留第二问最优参数”“第二问模型已获证实，因此第三问海马状态可信”等表述。

还应补充，V2 的提示与目标分别模拟，再进入独立通路，是对共享非线性网络的进一步结构简化；它不是把 V1 共同驱动下的非线性响应作严格代数分解。因此新旧差异不只来自一个记忆参数。

**5. V2 对提示记忆的定义比 V1 清楚，但两版不能合写为同一组方程。**

V1 中 `v` 同时含提示与目标驱动，记忆方程受整个 `v` 驱动，所以目标出现后也会更新记忆。若记忆表示“持续更新的任务信息”，该方程可以成立；若论文将其专门称作“此前提示的保持痕迹”，则存在语义混用。

V2 将记忆状态限定为由提示通路驱动，目标通过提取门和独立目标整合通路发挥作用，与“先保持提示、再提取”的叙述更一致。V2 还将反馈固定为零。因此建议以 V2 方程为第三题主模型，将 V1 作为初始模型/对照，不能在 V2 结果旁继续描述 V1 的双向反馈为新版特征。

V2 的错误和超时仿真仍沿用 V1，并已在报告明确注明。这可以保留为机制示例，但不能把 V1 的模拟正确率归入 V2 的实测性能或新版决策拟合结果。若要求整篇只有一个统一最终生成模型，则需要另外把决策层接到 V2 状态并重新模拟；本次未做该扩展。

**6. 事件标记处理与前两题没有冲突，但第三题的行为解释仍有未验证前提。**

三题的提示方向均来自 VisCue。三角朝向、目标所在左右位置、点击位置和 F3/F4 电极侧别是不同变量。项目二提示朝向与点击左右不一致，不等于答错；B1 第 49、87 次提示与平台符号不一致，也不能直接判定错误。

原题明确说明 TgtAct 的 ±2 是点击，但没有明确解释 ±1 平台起止。Q3 将平台起点当候选目标、Task-1 平台终点当应答代理，并在字段中保留假设标记。Task-2 有独立点击且与平台终点重合，不能据此将 Task-1 的代理身份写成已证实的点击。

正确率、错误率和超时率没有可确认的实测标签，因此只能验证假设模型中的决策机制；不能声称已经完成实测正确/错误分类。当前报告对此的限制是自洽的，但“题目要求均已实现”宜明确区分“模型与仿真已实现”和“实测行为标签验证未完成”。

进一步的模型局限是：V2 目标输入只有共同驱动，不含逐次目标形状与左右布局，因而没有显式计算“提示记忆与实际目标是否匹配”。它能检验保持/提取的功能性慢状态，尚不能完整解释项目二逐次 what/where 判断和错误来源。该局限不等于与 Q2 相矛盾，但论文不应把功能状态模型扩写为已验证的目标识别全过程。

Q3 将认知窗分为编码、保持、目标后整合三个分析段，不等同于题目中包含运动应答的三个阶段；只要仍截断于应答前并说明运动前准备仍可能残留，这个分段没有概念冲突。

**7. 三题的负结果彼此一致，指标不能跨题直接排行。**

Q1 支持有限的代理去噪收益和波形特征保留，并未建立稳定的未知方向识别或真实脑源恢复。当前 Q2 的机制特征分类证据不足，与 Q1 的有限结论相容。Q3 进一步发现慢记忆模型尚未稳定胜过一般慢趋势，也与前两题的证据边界一致。去噪指标改善不推出分类必然成功，分类不足也不禁止建立和检验候选生成模型。

Q1 的代理 MAE、Q2 条件平均 ERP 的 RMSE/R²、Q3 长窗单试次 RMSE 是不同预测目标；不能看到 Q3 数百单位的误差就断言前两题被推翻。Q3 总表按试次等权，部分模型比较按块等权，也应保留各自定义，不能强求从总表 RMSE 直接得到所有区间表中的比例。

V2 相对 V1 的目标后 EEG 比较如下，S=1−MSE_V2/MSE_V1，按块等权：

| 数据组 | S | 块重采样 95% 区间 |
|---|---:|---|
| A1 | 2.07% | −0.14%～5.36% |
| A2 | 2.22% | 1.24%～3.28% |
| B1 | 0.03% | −0.39%～0.26% |
| B2 | −2.37% | −5.53%～0.93% |

所以“3/4 组点估计改善”正确，“全面显著改善”不正确。仅输入刺激的 V2 N2 相对一般慢趋势 N3，四组目标后比较区间全部跨零。背景辅助的 22.8%～55.1% 收益比较的是有无提示前 EEG 信息，不能解释为记忆模块带来的增益。

本次从逐试次预测重算的合并行为 MAE：普通 EEG 前缀 0.12458248 秒，V1 认知前缀 0.12473629 秒，V2 认知前缀 0.12414961 秒。V2 相对普通前缀改善约 0.433 ms，报告区间为 −3.58～4.11 ms；相对 V1 改善约 0.587 ms。不能从这些点估计推出稳定的行为增益。现有报告总体没有越过这些证据边界。

**8. 当前目录还存在复现问题，应与科学结论分开处理。**

直接运行 README 中第三题测试命令时，`q3/model.py:10` 和 `q3/v2/model.py:11` 导入小写 `q2`，但当前目录是大写 `Q2`，实际出现 `ModuleNotFoundError: No module named 'q2'`。本次仅在测试进程中将 `Q2` 注册为 `q2` 别名，未修改源码；随后 18 项 Q3/V2 测试全部通过，包括目标到来前与 Q2 视觉响应的一致性、因果前缀、训练测试隔离和记忆门控测试。

保存清单与本地文件的逐字节哈希存在差异：V1 有 11 项，V2 有 23 项。对这些文件仅将 CRLF 还原为 LF 后全部匹配，未发现本次清单核对中有超出换行符的差异。这意味着原审计脚本严格字节哈希在当前检出环境下会失败，不能直接将以前的“通过”日志视为当前命令可以原样运行。应统一目录命名，并记录/处理跨平台换行策略，而不是为通过审计随意改写历史哈希。

此外，Q1 部分空间差分采用 F3−F4，Q2 正文的侧化指标采用 F4−F3。两者本身均可定义，但整合图表时必须写清符号转换，不能把数值正负的反转解释为生理结论反转。
