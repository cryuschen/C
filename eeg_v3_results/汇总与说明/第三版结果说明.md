# V3 第一问图表与指标说明

现有结果按受试者和项目放入 `受试者A_项目一`、`受试者A_项目二`、`受试者B_项目一`、`受试者B_项目二` 四个文件夹；跨项目图、半合成验证及汇总文件分别放在同名分类文件夹中。本次整理只移动已有文件。原脚本重新运行时仍会在 `eeg_v3_results` 根目录生成英文文件名，不会自动归类。

在项目根目录安装 `requirements-v3.txt` 所列 Python 依赖后，运行 `python EEG_P300_artifact_correction_v3.py` 可从 `data/` 中四组 `.mat` 数据重新生成本目录。仅使用原始 Fz、F3、F4 通道和 VisCue 事件；不使用题目提示避免直接采用的 FzDecon、F3Decon、F4Decon 通道。刺激前后窗口为 −250 至 800 ms，P300 分析窗为 250 至 500 ms。数据未给出可靠物理单位，图中统一标注为“原始电位单位”，面积单位为“原始单位·ms”。

## 图表

每组数据均生成以下四类新增图：

- `受试者A_项目一_典型试次原始与去噪对比图.png` 等：左、右刺激分别选可用试次中伪影评分约 75% 分位的单试次，展示基线对齐的原始信号与“预处理 + V3”结果。
- `受试者A_项目一_左右刺激三通道ERP对比图.png` 等：左右刺激分列，Fz、F3、F4 分行，显示 V3 前（已带通）与 V3 后的 ERP。
- `受试者A_项目一_P300时间窗放大图.png` 等：250–500 ms 局部波形与同方向低伪影参考模板。
- `受试者A_项目一_试次时间热力图.png` 等：Fz 的试次 × 时间热力图。左右刺激分组，V3 前后共享同一色标。

原有三通道拟合、左右差分、跨任务图及半合成注入测试图也会更新。严重坏试次不进入这些 ERP 图或后续指标。

## 指标与比较口径

`受试者A_项目一_评价指标.csv` 等文件每行对应一个刺激方向和通道。`第一问评价指标汇总.csv` 对六行指标取均值，并给出全部试次、剔除试次、保留率及评价试次数。`左右刺激与额区空间差异指标.csv` 给出左减右 ERP 和 F3 减 F4 的空间差分。V3 前指 60 Hz 陷波、0.1–30 Hz 带通并按刺激前中位数基线校正后的信号；V3 后在此基础上经过自适应校正。单试次原始对比图的“原始”另有明确标注。

低伪影参考模板由每个方向中质量较高的一半可用试次构建。参考误差仅在**未参加参考模板**的试次上计算，避免被评价的试次直接进入自己的参考。该参考仍只是实测数据的代理参考，并非无噪声真值；不能把其误差下降单独解释为神经特征完全保留。

| 指标列 | 定义 |
| --- | --- |
| `baseline_RMS_*` | 每试次 −250 至 0 ms 的 RMS，再对评价试次取均值。 |
| `trial_PTP_median_*` | 每试次完整窗口峰峰值，再取中位数。 |
| `SNR_proxy_dB_*` | 0–500 ms 的 ERP 均方功率 / 试次相对 ERP 的残差均方功率，取 10log10。残差包含真实试次变异，因此是代理 SNR。 |
| `edge_band_ratio_*` | Welch PSD 中 1–3 Hz 与 20–30 Hz 的合计功率占 1–30 Hz 功率比例。短试次频率分辨率约 1 Hz，此项仅描述边缘频段能量，不能单独认定为噪声。 |
| `MAE_*`、`RMSE_*` | 250–500 ms 评价 ERP 与低伪影参考 ERP 的绝对误差均值和均方根误差。 |
| `corr_*`、`shape_distance_*` | 同窗口 Pearson 相关和两条 z 标准化波形的平均绝对距离。 |
| `P300_positive_mean_*`、`P300_AUC_*` | 250–500 ms 中 `max(ERP, 0)` 的平均幅值和时间积分。 |
| `amp_error_*`、`latency_error_*` | 同窗口正峰值及其采样时刻相对低伪影参考的绝对误差。窗口内没有正峰时，峰值和潜伏期留空。 |
| `retention_ratio` | 空间或左右差分在 250–500 ms 的 V3 后范数 / V3 前范数；接近 1 仅表示幅度相近，还需一起看 `waveform_correlation`。 |
| `trial_retention_percent` | 可用试次 / 全部试次 × 100%。 |

半合成注入测试使用相同背景构成左右条件，保存注入信号、已知污染前波形和恢复波形。它验证指定注入场景，不能代替真实无噪声 EEG 真值。各通道的三高斯拟合若失败，会写入 `fit_status=smooth_fallback`，拟合参数、R² 与 RMSE 留空；此时平滑线仅作展示。

题目仅提供额区 Fz/F3/F4 记录点。这里的 250–500 ms 正向响应称为 P300 分析窗特征，不据此断言已观测到典型中央或顶区 P300 的空间分布。
