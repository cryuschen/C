# 第三问 V2：有边界的结构优化

V1 已完成建模，但实测增量有限。V2 在查看新版成绩前固定以下工程方案；这不是外部预注册。本数据已反复开发，外层留块仍仅是内部探索验证。

1. 完全复用 V1 的原始三通道、因果滤波、有效试次、评分掩码与五块划分；不因新成绩改变降噪强度或剔除标准。
2. 将提示视觉响应、共同目标响应分开。只有提示通路写入记忆状态，目标后的提取门激活保持信息；目标不再写入旧提示记忆。
3. 固定有效延迟 50 ms，主模型关闭反馈，提取驱动尺度固定为 1。减少与观测幅度混淆的动力学参数，不声称这三个常数被实测确定。
4. 提示共同成分与朝向差分采用独立收缩：方向惩罚倍率 {1,10}；目标共同输入持续时间 {.1,.2,.4} s。均仅在训练内层选型，不使用点击方向或反应时生成输入。
5. τm={.5,1,2,4} s，τp={.1,.3,.6} s。N0 视觉、N1 视觉+普通低通、N2 记忆整合、N3 视觉+平滑趋势。无直接记忆投影、无提取门、固定目标时长、等强度惩罚均重拟合。
6. 主结果为仅输入刺激事件。另设提示前背景辅助预测：只从提示前 8 秒因果滤波 EEG 计算三种时间尺度的历史斜率，用固定衰减形状和训练内估计系数外推。所有模型均获得相同背景信息，并设置 B0 纯背景基线。背景改善不能归因于记忆，不能与刺激输入方案混成一个排名。
7. 两种设定都直接评分原 V1 EEG；不删除慢波或重新标度测试目标。行为仍只读目标后 600 ms 以内 EEG，使用独立前缀队列与完整嵌套选型、1999 次块内置换和 2000 次块重采样。
8. 不改写原 `q3_result`。新增结果位于 `q3_result_v2`，原决策仿真仍作为机制示例，不冒充新版实测行为拟合。

从项目根目录运行：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python -B q3/v2/run.py
.venv/bin/python -B -m unittest discover -s q3/tests -v
.venv/bin/python -B q3/v2/audit.py
```

也可使用 `--stage eeg|behavior|recovery|render` 分阶段运行。`--output` 指定独立结果目录。测试、原始结果比较、半合成恢复和图表复核均保留证据。
